Online registration-এর জন্য Supabase Project URL ও Publishable key ব্যবহার করুন। Secret key কখনো browser app-এ দেবেন না।

Publishable key সাধারণত sb_publishable_... দিয়ে শুরু হয়। Secret key (sb_secret_...) ব্যবহার করবেন না।

Online Data Tables
